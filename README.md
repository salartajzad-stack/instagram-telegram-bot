# ربات تلگرام دانلود اینستاگرام

این ربات لینک پست، ریلز یا IGTV عمومی اینستاگرام را می‌گیرد و فایل عکس/ویدئو را در تلگرام ارسال می‌کند.

## ۱) ساخت ربات در تلگرام

1. در تلگرام وارد `@BotFather` شوید.
2. دستور `/newbot` را بفرستید.
3. نام و نام کاربری ربات را تعیین کنید؛ نام کاربری باید به `bot` ختم شود.
4. توکن دریافتی را محرمانه نگه دارید و برای هیچ‌کس نفرستید.

## ۲) اجرای ساده با Docker

```bash
docker build -t instagram-telegram-bot .
docker run -d --restart unless-stopped \
  --name instagram-telegram-bot \
  -e TELEGRAM_BOT_TOKEN="توکن_ربات" \
  instagram-telegram-bot
```

## اجرای مستقیم با Python

Python 3.11 یا جدیدتر و `ffmpeg` باید نصب باشند.

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="توکن_ربات"
python bot.py
```

## نکات مهم

- کامپیوتر یا سروری که ربات روی آن اجرا می‌شود باید همیشه روشن و متصل به اینترنت باشد.
- این نسخه فقط لینک‌های عمومی را پشتیبانی می‌کند. پست‌ها و استوری‌های خصوصی معمولاً به ورود حساب اینستاگرام و کوکی نیاز دارند.
- توکن را در فایل کد، چت عمومی یا GitHub قرار ندهید.
- فقط محتوایی را دانلود کنید که اجازه ذخیره یا استفاده از آن را دارید.
